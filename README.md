# 日本訪問看護学会 公式サイト（WordPress）

訪問看護の「あたたかさ」と、学会としての「学術的な信頼感」を両立させた
WordPress カスタムテーマ **JSVN** とローカル開発環境一式です。

> 学会は創設準備中のため、文言・配色・構成はすべて「たたき台」です。
> 後からブラウザ上の管理画面・カスタマイザーで差し替えられる設計にしています。

---

## デザインコンセプト

| 観点 | 方針 |
| --- | --- |
| 温かさ（訪問看護） | セージグリーン × クリーム地 × コーラルのアクセント |
| 学術性（学会） | 深いネイビー、見出しに**明朝体**（Noto Serif JP） |
| 親しみ・可読性 | 本文は**ゴシック体**（Noto Sans JP） |
| 「入会したくなる」体験 | トップに入会導線、メリット提示、会費の見える化 |

カラーやフォントは `wp-content/themes/jsvn/style.css` 冒頭の
「デザイントークン（CSS変数）」を書き換えるだけで全体を一括調整できます。

```css
:root {
  --jsvn-green: #2f7d63;  /* 訪問看護のグリーン */
  --jsvn-navy:  #1f3a5f;  /* 学術の信頼感     */
  --jsvn-coral: #e08a6e;  /* 温もりのアクセント */
  /* ... */
}
```

## ローカルで動かす（Docker）

Docker と Docker Compose があれば、すぐに確認できます。

```bash
docker compose up -d
```

1. ブラウザで <http://localhost:8080> を開く
2. WordPress の初期設定（言語・サイト名・管理者）を済ませる
3. 管理画面 **[外観 > テーマ]** で「**JSVN - 日本訪問看護学会**」を有効化

停止・削除:

```bash
docker compose down          # 停止（データは残る）
docker compose down -v       # データベースごと削除
```

## 公開サーバーへの導入（レンタルサーバー等）

1. 既存の WordPress の `wp-content/themes/` 配下に `jsvn` フォルダをアップロード
   （またはこのフォルダを zip 化して [外観 > テーマ > 新規追加 > アップロード]）
2. テーマを有効化
3. 下記「初期設定」を実施

---

## 有効化後の初期設定（推奨）

### 1. トップページの設定
- **[設定 > 表示設定]**
  - 「ホームページの表示」→ **固定ページ**
  - ホームページ：新規固定ページ「ホーム」（中身は空でOK。`front-page.php` が優先表示されます）
  - 投稿ページ：新規固定ページ「お知らせ」

### 2. メニューの作成
- **[外観 > メニュー]** で「グローバルメニュー」を作成し、表示位置に割り当て
  - 推奨項目：学会について / 学術大会 / 学会誌 / お知らせ / 入会案内 / お問い合わせ
- 上部バー用に「ユーティリティメニュー」も作成可能（会員ログイン・お問い合わせ等）

### 3. 固定ページの作成
ヘッダー・フッターのリンクに対応する以下のページを作成すると導線が完成します。

| スラッグ | ページ |
| --- | --- |
| `/about/` | ご挨拶・理念 |
| `/join/` | 入会のご案内 |
| `/contact/` | お問い合わせ |
| `/events/` | 学術大会・研究会（カスタム投稿のアーカイブ） |
| `/journal/` | 学会誌・刊行物（カスタム投稿のアーカイブ） |

### 4. お知らせのカテゴリー（色分け）
**[投稿 > カテゴリー]** で以下のスラッグを作ると、一覧でラベル色が変わります。

| スラッグ | 色 | 用途 |
| --- | --- | --- |
| （任意） | グリーン | お知らせ全般 |
| `event` | コーラル | イベント |
| `academic` | ネイビー | 学術関連 |

## カスタム投稿タイプ

テーマ有効化時に自動登録されます。

- **学術大会・研究会**（`jsvn_event`） … 管理画面メニュー「学術大会」
- **学会誌・刊行物**（`jsvn_journal`） … 管理画面メニュー「学会誌」

> 有効化直後に個別ページが 404 になる場合は、**[設定 > パーマリンク]** を
> 一度「保存」してリライトルールを更新してください。

## ファイル構成

```
wp-content/themes/jsvn/
├── style.css          テーマ情報 + 全スタイル（デザイントークン）
├── functions.php      テーマ設定・メニュー・カスタム投稿タイプ
├── header.php         ヘッダー / グローバルナビ
├── footer.php         フッター
├── front-page.php     トップページ（ヒーロー〜入会CTA）
├── index.php          お知らせ一覧（フォールバック）
├── page.php           固定ページ
├── single.php         個別記事
├── archive.php        アーカイブ（カテゴリ・カスタム投稿）
├── search.php         検索結果
├── searchform.php     検索フォーム
├── sidebar.php        サイドバー
├── 404.php            404ページ
└── assets/
    ├── css/
    ├── js/main.js     モバイルメニュー等
    └── images/
```

## 今後のカスタマイズの進め方

1. **文言の差し替え**：トップページの仮テキストは `front-page.php` 内にあります。
   実コンテンツが固まったら、固定ページ／カスタマイザー連携へ段階的に移行できます。
2. **ロゴ**：[外観 > カスタマイズ > サイト基本情報] でロゴ画像を設定すると
   仮の「看」マークが置き換わります。
3. **色の微調整**：`style.css` の CSS 変数を変更。
4. **写真**：訪問看護らしい温かみのある写真をアイキャッチに設定すると印象が大きく向上します。
