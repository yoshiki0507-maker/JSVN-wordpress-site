日本訪問看護学会の公式サイト用カスタムテーマです。
訪問看護の「あたたかさ」と学会としての「学術性・品格」を両立したデザイン。

== インストール手順 ==

1. WordPress管理画面 [外観 > テーマ > 新規追加 > テーマのアップロード] を開く
2. この zip ファイル（jsvn.zip）を選択してインストール
3. 「有効化」する
4. [設定 > パーマリンク] を一度「変更を保存」する
   （役員・学術大会などのカスタム投稿タイプのURLを有効化するため）

== 有効化すると自動で作成されるもの ==

- 固定ページ一式（設立趣旨・理念／理事長挨拶／学会概要／会員数・会員分布／
  定款／役員紹介／倫理綱領／利益相反(COI)／学会誌・投稿規定／入会案内／
  よくある質問／プライバシーポリシー ほか）
- 役員名簿（サンプル：理事長1・副理事長2・常任理事3・理事15）
- グローバルメニュー（ドロップダウン構成）

== 主な編集場所 ==

- トップ・ヘッダー・フッターの文言： [外観 > カスタマイズ > サイトの文言（テキスト編集）]
- ロゴ： [外観 > カスタマイズ > サイト基本情報]
- メインビジュアル画像： [外観 > カスタマイズ > メインビジュアル（トップ画像）]
- SNSのURL： [外観 > カスタマイズ > SNS・ソーシャル]
- 学会バンクのログインURL： [外観 > カスタマイズ > 会員・学会バンク]
- 各ページ本文： [固定ページ]
- お知らせ・ブログ： [投稿]（カテゴリー blog でブログ欄に表示）
- 役員名簿： [役員名簿]
- 学術大会： [学術大会]
- 会員数・資格別人数： functions.php の jsvn_member_counts() /
  jsvn_member_qualifications()（学会バンク連携や手入力に差し替え可能）
- 協賛企業バナー： [外観 > ウィジェット > 協賛企業バナー（トップ右）]
